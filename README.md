# Artemis
Artemis is an experimental UI project for me. Being a design enthusiast, someone who craves interation at every gesture on screen and someone who's in love with game UIs, I wanted to try to bring these world together in this experiment.

I've only recently started working on this, and this is still ongoing.

## Contribution
This is supposed to be a personal project for me, but I would love to get suggestions on what I should add, or any form of suggestions.
